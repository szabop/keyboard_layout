# Custom Keyboard Layout

This layout is basically a US layout, with the following changes:

- Z and Y are swapped
- Hungarian accented characters are accessible with Option + <left hand>

| Combinaiton | Character |
|:------------|----------:|
| Option + a  |         á |
| Option + s  |         é |
| Option + d  |         ó |
| Option + f  |         ú |
| Option + e  |         ő |
| Option + r  |         ű |
| Option + y  |         í |
| Option + x  |         í |
| Option + c  |         ö |
| Option + v  |         ü |

## Installation

1. copy the file into `PHun.layout` into directory `~/Library/Keyboard Layouts/`
2. reboot the machine
3. add the layout in System Settings > Keyboard, then under Text Input choose Edit, then +, and choose the layout.
